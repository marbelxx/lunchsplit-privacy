  • 개인정보를 수집하지 않습니다. 회원가입·로그인이 없고, 운영하는 서버도 없습니다.
  • 모든 데이터는 사용자의 iPhone에만 저장됩니다. 개발자를 포함한 누구에게도 전송되지 않습니다.
  • 영수증 인식도 iPhone 안에서만 처리합니다. 사진이나 글자를 외부로 보내지 않습니다.
  • 광고·분석 도구·추적이 없습니다.

1. 처리하는 정보와 저장 위치

점심N빵(이하 “앱”)은 사용자가 직접 입력하거나 촬영한 아래 정보를 앱 기능을 위해 사용자의 iPhone 안에만 저장합니다. 개발자는 이 정보에 접근할 수 없습니다.

정보용도
영수증·카드전표 사진메뉴·금액 자동 입력, 증빙 보관
식사 기록(날짜, 가게 이름, 메뉴, 금액, 메모)N빵 계산, 가계부
함께 먹은 사람의 이름(사용자가 입력한 별칭)과 메모사람별 부담금·정산 계산
정산·입금 기록받을 돈 관리
내 이름, 입금 계좌(은행·계좌번호·예금주), 정산표 문구정산표에 표시

2. 영수증 인식

영수증 글자 인식에는 Apple의 Vision 프레임워크를, 메뉴·금액 정리에는 기기 내 Apple Intelligence(Foundation Models)를 사용합니다. 두 기능 모두 iPhone 안에서만 동작하며, 앱은 사진이나 인식 결과를 어떤 서버에도 보내지 않습니다.

3. 앱이 요청하는 권한

  • 카메라: 영수증을 촬영할 때만 사용합니다.
  • 사진 선택: 사용자가 고른 영수증 사진만 앱으로 가져옵니다. 사진 보관함 전체를 읽지 않습니다.
  • 사진 보관함에 추가: 정산표 이미지를 앨범에 저장할 때만 사용하며, 기존 사진은 읽지 않습니다.

권한은 iPhone 설정 > 점심N빵에서 언제든 끌 수 있습니다. 권한을 끄더라도 직접 입력 등 나머지 기능은 사용할 수 있습니다.

4. 제3자 제공과 공유

앱은 정보를 제3자에게 제공하지 않습니다. 사용자가 직접 “카카오톡으로 보내기”나 “백업 파일 내보내기”를 선택한 경우에만, 사용자가 고른 앱(예: 카카오톡, 파일, 메일)으로 정산표나 백업 파일이 전달됩니다. 이후의 처리는 해당 앱의 방침을 따릅니다.

사람별 정산표에는 받는 사람 본인의 내역만 들어가며, 다른 사람의 이름이나 금액은 포함되지 않습니다.

5. 보관 기간과 삭제

  • 정보는 사용자가 지우거나 앱을 삭제할 때까지 iPhone에 보관됩니다.
  • 기록·멤버는 앱 안에서 언제든 지울 수 있고, 앱을 삭제하면 모든 데이터가 함께 지워집니다.
  • 백업 파일은 사용자가 저장한 위치(파일 앱 등)에 남으므로 필요 없으면 직접 지워 주세요. 백업 파일에는 영수증 사진과 계좌 정보가 들어 있으니 안전한 곳에 보관하세요.

6. 아동의 개인정보

앱은 어떤 사용자의 개인정보도 수집하지 않으며, 만 14세 미만 아동의 정보도 수집하지 않습니다.

7. 방침의 변경

방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다. 정보를 수집하거나 외부로 보내는 기능이 생긴다면, 그 전에 앱 안에서 먼저 알리고 동의를 받습니다.
